CORS - Cross Origin Resource Sharing

It is asecurity mechanism to make resource sharing in web safer

preflight request is sent from one domain client side - origin - fb.com

options response is sent from other domain server side - server api - gb.com

There are many options but main one are -

Access-Control-Allow-Origin: * (passing domains in it restrict which domain request are whitelisted, * means no restrictions)

Methods: (passing methods like post, put etc. in it restrict which method apis request are whitelisted)

Then the final post or get request is sent to other server
